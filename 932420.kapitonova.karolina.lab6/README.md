Лабораторная работа №6, вариант 16

Автор: Каролина Капитонова, группа 932420.

Тема: «Конвертер температур».

Цель: изучить основы Node.js, создание сервера на Express и работу приложения без сети.

Создан сервер, который отдаёт страницы сайта, стили, скрипты и изображения. Добавлены главная страница, страница «О себе» и маршрут проверки состояния сервера.

Реализован конвертер температур между градусами Цельсия, градусами Фаренгейта и Кельвинами. Форма передаёт температуру и выбранные единицы на сервер. Сервер выполняет расчёт и возвращает результат в формате JSON.

Добавлена проверка входных данных. Если передано не число или неизвестная единица температуры, сервер возвращает ошибку 400.

Подключён манифест с названием и иконками приложения. Сайт можно установить как PWA и открывать в отдельном окне.

Service worker сохраняет файлы сайта в кеш. После первого посещения страницы открываются без сети, а конвертер выполняет расчёт в браузере.
