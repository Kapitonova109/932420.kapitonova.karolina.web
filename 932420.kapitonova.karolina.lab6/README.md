Сайт — страницы, стили и скрипты, которые показываются в браузере.
Сервер и запуск — сервер Express и настройки npm.
Сайт/Изображения — фотография и иконки приложения.

Для запуска открой Git Bash и введи:

```bash
cd "/d/HTML/932420.kapitonova.karolina.lab6/Сервер и запуск"
npm start
```

Открой http://localhost:3000 в браузере. Терминал оставь открытым.
Для остановки сервера нажми Ctrl+C.

На этом компьютере зависимости уже установлены. При первом запуске новой копии проекта выполни npm ci в папке «Сервер и запуск».

Маршруты:
/ — главная страница.
/about — страница «О себе».
/api/status — статус сервера.
/api/temp?value=25&from=C&to=F — перевод 25 °C в 77 °F.

Конвертер принимает C, F и K. При неверных параметрах сервер возвращает 400.
Манифест и service worker позволяют установить приложение и открыть его без сети после первого посещения.

В папке «Сервер и запуск» npm создал node_modules и package-lock.json. Это установленные библиотеки и список их версий. Их содержимое разбирать для защиты не нужно.
